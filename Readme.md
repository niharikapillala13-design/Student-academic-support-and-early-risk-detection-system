Student Academic Support and Early Risk Detection System

Project Description

This project analyzes student academic data to identify students who may be at academic risk and help improve their academic performance.

Objectives

- Clean and preprocess student data.
- Analyze student academic performance.
- Visualize student data using graphs.
- Identify students who may need academic support.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Files

- "cleaning.ipynb" – Data cleaning and preprocessing.
- "load_dataset.ipynb" – Loading the dataset.
- "Data_Visualization.ipynb" – Visualizing student data.
- "cleaned_dataset.csv" – Cleaned dataset.
- "all_csv_combined.csv" – Combined dataset.

Current Progress

Data loading, data cleaning, and data visualization.

Future Scope

Implement machine learning models to predict academic risk and provide early support to students.

Conclusion

This project aims to support students by analyzing academic data and identifying potential academic risks at an early stage.
